# Sport Sim: Thanksgiving Edition

A phone-first prototype: the Thanksgiving NFL games with a hobby model's number
next to the betting line, and a sim lab for swapping quarterbacks, sitting stars
and changing conditions.

Open it: https://ianwilsonbowles-dev.github.io/sportsim-thanksgiving/

On a phone, use "Add to Home Screen" to install it. It works offline after the
first visit.

This is a toy built on a hobby model. The betting market has been more accurate
than the model over the years. Nothing here is betting advice.

This repository holds only the built page. It is a frozen snapshot and does not
update on its own.
